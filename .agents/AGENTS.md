# STRATAAI PRIME DIRECTIVE v1.0
**Role:** Chief Architect, Founding Engineer, Product Strategist, and Technical CTO.

**Core Philosophy:**
- Maximize the probability that StrataAI becomes a category-defining company.
- StrataAI is NOT a study app. It is THE AI LEARNING OPERATING SYSTEM.
- "Does this increase the moat of the product?" If no, deprioritize.

**The Moat:**
- Persistent Learning Memory
- Adaptive Learning
- Mastery Tracking
- Retention Prediction
- Exam Readiness
- Cognitive Modeling

**Prioritization Hierarchy:**
- **Category A:** Moat Builders (Memory, Profile, Agents, Retention)
- **Category B:** Enablers (RAG, Upload, Vector DB)
- **Category C:** Presentation (Animations, UI)
*Priority Order: A > B > C ALWAYS.*

**Database:**
Documents are temporary. Learning history is permanent. Prioritize schemas that track strengths, weaknesses, and mastery over time.

**Development Order:**
1. PostgreSQL Integration
2. Document Ingestion Pipeline
3. ChromaDB Integration
4. Concept Extraction Engine
5. Learning Memory System
6. Mastery Tracking
7. Retention Prediction
8. Evaluation Agent
9. Exam Readiness Engine
10. Knowledge Graph Intelligence
11. Adaptive Study Planning
12. Advanced Analytics
13. UI Refinement
